AD SARAH FORTUITO — PORTFOLIO WEBSITE
=====================================

HOW TO VIEW IT
--------------
Unzip the folder, then double-click portfolio.html.
It opens in any browser. No internet needed except for the fonts.

IMPORTANT: Keep every file in the SAME folder.
The HTML loads the images and videos by filename, so moving
or renaming any file will break that part of the page.


HOW TO PUT IT ONLINE (free options)
-----------------------------------
1. Netlify Drop  — netlify.com/drop
   Drag the whole unzipped folder onto the page. Live in seconds.

2. GitHub Pages
   Create a repo, upload all files, then enable Pages in
   Settings > Pages > Deploy from branch (main, root folder).

3. Vercel — vercel.com
   Import the folder, deploy. No configuration needed.

UPDATING IT LATER
-----------------
To swap a photo: replace the file, keep the exact same filename.
To change any text: open portfolio.html in Notepad, TextEdit,
or VS Code and edit the words between the tags.

Your contact details appear in two places in the file:
the Contact section and the footer.
